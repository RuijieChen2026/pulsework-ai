# PulseWork — 企业通用 AI 工作助手

> 面向 2027 届 AI 产品经理校招的产品作品。这不是一个聊天套壳，而是一个将企业知识、用户上下文、Agent 执行与评测迭代组成闭环的产品原型。

## 一句话介绍

PulseWork 是面向全体员工的企业通用 AI 工作助手：它能基于权限检索企业知识，理解个人与业务上下文，调用企业系统完成任务，并对高风险操作设置人工确认。

## 为什么做这个产品

企业内部不缺系统，缺的是一个能跨知识、跨系统理解用户目标的入口。员工的实际任务往往是：先找制度，再判断自己是否符合，然后切换多个系统完成操作。PulseWork 从“回答问题”走向“完成任务”。

## MVP 场景

1. **RAG 制度问答**：混合检索、重排、段落级引用、有效期校验。
2. **差旅报销 Agent**：读取发票、核对标准、补齐信息、征得确认后提交。
3. **入职协作 Agent**：基于岗位与地区生成清单，跨 HR、IT、行政分派任务。

## 产品原则

- **来源可追溯**：答案引用到原文段落，展示文档版本与日期。
- **权限不放大**：Agent 不能看到用户本人无权访问的内容。
- **先规划再执行**：工具调用可见，写操作与高风险操作需确认。
- **失败可恢复**：信息不足时先澄清，工具失败时保留上下文与重试入口。

## 评测体系

评测集将真实业务场景脱敏后分成正向、边界和对抗三类，分别衡量正确性、归因性、工具选择、任务成功、安全合规和延迟。示例数据见 [`evals/dataset.json`](./evals/dataset.json)。
