# PulseWork MVP PRD

## 1. 目标

在公司制度查询、差旅报销和新人入职三类通用场景中，降低用户的信息搜索成本和跨系统操作成本。

## 2. 用户与需求

| 用户 | 核心任务 | 现有痛点 |
| --- | --- | --- |
| 普通员工 | 找到适用制度并完成流程 | 文档分散、版本不清、切换系统 |
| 新员工 | 完成入职后首周准备 | 不知道找谁、依赖关系不透明 |
| 职能运营 | 减少重复咨询并优化制度 | 缺少问题聚类与效果数据 |

## 3. 用户故事

- 当我询问差旅制度时，我希望看到与自己地区、职级相符的答案和原文。
- 当我提供发票后，我希望系统先告诉我缺少什么，再由我确认提交。
- 当我刚入职时，我希望一次看到所有任务、负责人和依赖关系。

## 4. 功能范围

### P0

- 文档接入、切分、混合检索、重排与段落引用
- 基于用户身份的检索权限过滤
- Agent 计划展示、工具调用、写操作人工确认
- 会话反馈、追踪与回归评测

### 非目标

- MVP 不允许 Agent 自主执行付款、删除、权限变更等高风险操作
- 不在首版支持用户自定义 Agent 工作流

## 5. 指标

- 北极星：有效任务完成率
- 质量：答案正确率、引用正确率、任务成功率
- 效率：平均处理时长、系统切换次数
- 安全：越权检索数、未确认写操作数（目标均为 0）

## 6. 灰度策略

1. 内部 20 名种子用户，只开放只读问答。
2. 开放差旅报销沙箱执行，所有提交需二次确认。
3. 按地区和职能扩大范围，每周回收低分会话进入评测集。
